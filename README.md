Project Feasibility Study

This repository contains the feasibility study for the proposed Web-based Centralized Faculty Evaluation System for Benedicto College.

The feasibility study covers:

Technical Feasibility – Availability of the required hardware, software, and technologies.
Financial Feasibility – Estimated costs and availability of free or open-source development tools.
Operational Feasibility – The system's ability to improve and support the current faculty evaluation process.

Technologies:
  Next.js
  React
  TypeScript
  Vite
  Tailwind CSS
  Node.js
  Express.js
  MySQL
